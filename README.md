# Quartet covariance — CT v14

*A Sum-of-Squares Decomposition for Quartet Covariance: Bivariate Independence and Quartet Distance*  
Stefan Grünewald and Libo Huang. Manuscript dated 22 November 2026.

- [Read the paper](Grunewald_Huang_CT_v14.pdf)
- [View the manuscript LaTeX](Grunewald_Huang_CT_v14.tex)
- [Download the paper and full Lean 4 project](Grunewald_Huang_CT_v14_Paper_and_Lean4_20261123.zip)
- [SHA-256 file hashes](SHA256SUMS)

The archive includes the LaTeX inputs, the complete Lean project, pinned toolchain
and mathlib dependencies, the manuscript-to-Lean correspondence, and the license
and verification records. Open the archive's README for build commands.

The Lean supplement covers Sections 2–4, Theorem 5.1, and the lower inequality
in Theorem 5.2. The upper inequality has been formalized conditionally on the
construction and per-depth estimates of the prefix and suffix trees.
