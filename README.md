# Quartet covariance — CT v14

*A Sum-of-Squares Decomposition for Quartet Covariance: Quartet Distance and Bivariate Independence*

Stefan Grünewald and Libo Huang. CT v14, 26 November 2026.

- [Read the paper](Grunewald_Huang_CT_v14.pdf)
- [View the manuscript LaTeX](Grunewald_Huang_CT_v14.tex)
- [Download the paper and full Lean 4 project](Grunewald_Huang_CT_v14_Paper_and_Lean4_20261126.zip)
- [SHA-256 file hashes](SHA256SUMS)

The archive includes the LaTeX inputs, the complete Lean project with its
toolchain and mathlib lock files, the manuscript-to-Lean correspondence, and
the license and verification records. Open the archive's README for build commands.

The Lean supplement covers the numbered results in Sections 2–4, Theorem 5.1,
and the lower inequality of Theorem 5.2. The proof of the upper inequality in
Lean assumes the diameter and per-depth estimates for a binary tree pair. The
manuscript establishes these hypotheses using prefix and suffix trees.
